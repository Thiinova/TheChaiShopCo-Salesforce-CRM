# TheChaiShopCo-Salesforce-CRM

## Project Overview

TheChaiShop&Co Salesforce CRM Application is a cloud-based customer relationship management solution developed using the Salesforce Platform.

The project is designed to centralize customer and business information, improve data accuracy, automate repetitive business processes, and provide reports and dashboards for business analysis.

## Objectives

- Centralize customer and business information
- Manage customer and order records
- Improve data accuracy using validation rules
- Automate business processes using Salesforce Flow
- Automate customer email notifications
- Calculate order-related billing information
- Generate reports and dashboards
- Control user access using Salesforce security features
